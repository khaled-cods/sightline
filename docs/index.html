How it works

Four steps, about ten seconds.

1. Open

Loads your page in a real Chrome at phone and desktop sizes.

2. Inspect

Measures contrast, image shapes, button sizes, labels, overflow and more.

3. Show

Draws numbered boxes on screenshots so the problem is visible.

4. Fix

Gives a score and a fix list. The AI edits the code and checks again.

See it catch real bugs

A phone page with four planted problems. Sightline marks each one.

Score 78/100 (C)

1. overflow-x Page scrolls sideways: 310px wider than the screen.

2. tap-target Button is 20×20px. People can't tap it.

3. image-crop Only 10% of the photo is visible.

4. text-clipped Text is cut off with no ellipsis.

fix: each item comes with the exact CSS change to make.

What it checks

Objective defects, not taste.

LayoutSideways scrolling, cut-off text, stretched or over-cropped images
TouchButtons and links too small to tap on a phone
AccessibilityLow contrast, missing image descriptions, unlabeled fields and buttons, heading order, page language
TypeText too small, too many fonts

Built for Arabic and right-to-left pages

Most tools ignore RTL. Sightline catches the mistakes that make Arabic sites look wrong.

Use it with your AI

In Claude Code, add it once and it runs after every UI change:

/plugin marketplace add khaled-cods/sightline

/plugin install sightline@sightline

Using another tool? Copy SKILL.md into its rules file. Free and open source (MIT).

Sightline is a heuristic checker. It finds objective defects, not design taste, and skips contrast over images and gradients instead of guessing.
